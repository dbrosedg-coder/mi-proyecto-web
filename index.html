Comandos Git que he aprendido

Resumen de los comandos que he usado en esta práctica:

  1. git init: crea un repositorio local.
  2. git add: prepara los cambios para el commit.
  3. git commit -m "mensaje": guarda los cambios.
  4. git push: sube los cambios a GitHub.
  5. git checkout -b rama: crea una rama nueva.
¿Qué es un Pull Request?

Es una petición para fusionar los cambios de una rama en main, revisándolos antes en GitHub.

¿Por qué trabajar con ramas?

Permite desarrollar cada mejora por separado sin romper la versión principal del proyecto.
